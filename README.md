# gui-file-organizer
File organizer that sorts files into their respective categories.

## Overview
A python application built with Tkinter which sorts files into their categories based on extensions and those without extensions are treated separately.

## Features
- Built with Tkinter.
- Sorts files into folders e.g. Archives, Documents, Images, Videos, Installers.
- Duplicate names are appended with the incrementing counter.

## Technologies Used
- Python 3
- Tkinter

## How To Run
- Open pre-installed Python3 application.
- Select folder to be organized.
- Organize files into their respective categories.
